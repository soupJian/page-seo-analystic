# Chrome SEO 分析插件

一个专业的 Chrome 扩展插件，用于分析网页的 SEO 信息，包括结构化数据、产品 offers 信息等。

## 功能特性

### 基础 SEO 分析

- 页面基本信息（标题、URL、语言、字符集）
- Meta 信息分析（description、keywords、author 等）
- Open Graph 数据提取
- 标题结构分析（H1-H6 层级）
- 图片信息分析（src、alt、尺寸）
- 链接信息提取（内部/外部链接分类）
- 分析工具检测（Google Analytics、GTM 等）

### 结构化数据分析

- 自动检测页面中的 JSON-LD 结构化数据
- 支持多种数据类型：Product、Organization、BreadcrumbList、Review、Event、Article 等
- 智能去重处理，避免重复显示

### 产品信息详细分析

- **产品基本信息**：名称、品牌、描述、图片、分类
- **产品标识符**：SKU、GTIN、MPN
- **价格信息**：价格、货币、价格范围
- **可用性信息**：库存状态、商品状态
- **评分信息**：平均评分、评论数量
- **卖家信息**：卖家名称、类型

### 🆕 多个 Offers 详细展示

- **完整的销售选项信息**：每个 offer 的详细信息
- **价格对比**：不同选项的价格比较
- **库存状态**：每个选项的库存水平
- **配送信息**：配送费用、时间、目的地
- **退货政策**：退货期限、方式、费用
- **卖家信息**：不同卖家的详细信息
- **产品变体**：颜色、尺寸等变体信息
- **保修信息**：保修期限和条款
- **地区限制**：适用和不适用地区
- **业务功能**：销售、租赁等业务类型

### 数据导出功能

- **图片信息导出**：导出为 Excel 格式，包含超链接
- **链接信息导出**：导出为 Excel 格式，包含超链接
- **🆕 Offers 信息导出**：导出所有销售选项的详细信息到 Excel
- **CSV 格式支持**：支持 CSV 格式降级导出

### SEO 优化建议

- 基于 Google SEO 指南的专业建议
- 优先级分类（高/中/低）
- 具体修复建议和官方文档链接
- 移动友好性、结构化数据完整性检查

## 安装方法

1. 克隆项目到本地

```bash
git clone <项目地址>
cd page-analystic
```

2. 安装依赖

```bash
npm install
```

3. 构建项目

```bash
npm run build
```

4. 加载到 Chrome
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择项目的 `dist` 文件夹

## 使用方法

1. **安装插件后**，浏览器工具栏会出现插件图标
2. **访问任意网页**，点击插件图标
3. **点击"分析当前页面"**按钮
4. **Chrome 侧边栏**会自动打开，显示详细的 SEO 分析结果

## 测试页面

项目包含一个测试页面 `test-offers.html`，包含复杂的产品结构化数据，可以用来测试插件的各项功能：

- 4 个不同的产品 offers
- 完整的配送信息
- 详细的退货政策
- 多种产品变体
- 复杂的价格结构

## 技术架构

- **构建工具**：Vite + TailwindCSS
- **扩展格式**：Chrome Extension Manifest V3
- **核心文件**：
  - `popup.js` - 插件弹窗界面
  - `content.js` - 页面内容分析
  - `sidebar.js` - 侧边栏显示逻辑
  - `background.js` - 后台消息处理

## 新增功能说明

### Offers 详细展示

新版本大幅增强了产品 offers 的展示功能：

1. **完整信息展示**：每个 offer 显示 35+个字段信息

- 基本信息：价格、货币、有效期

- 卖家：卖家名称、类型
- 配送：费用、时间、目的地
- 退货：政策、期限、费用
- 产品：SKU、GTIN、MPN、序列号
- 地区：适用地区、服务区域
- 其他：保修、交付时间、业务功能

## 开发说明

### 项目结构

```
page-analystic/
├── src/
│   ├── popup/          # 插件弹窗
│   ├── sidebar/        # 侧边栏界面
│   ├── content/        # 内容脚本
│   └── background/     # 后台脚本
├── public/             # 静态资源
├── dist/              # 构建输出
└── test-offers.html   # 测试页面
```

### 构建脚本

- `npm run build` - 构建生产版本
- `npm run dev` - 开发模式（监听文件变化）

### 文件大小

- `content.js`: ~15KB
- `sidebar.js`: ~27KB
- 总体积优化，适合 Chrome 扩展
